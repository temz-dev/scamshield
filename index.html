    How it works

    1. Paste anything suspicious — a DM, a tweet, a Telegram post, a link, or a token address.
    2. ScamShield scans it against 20+ known scam patterns: doubling promises, guaranteed returns, seed-phrase traps, impersonation, urgency tricks, lookalike domains, shorteners, raw-IP links, and token liquidity checks.
    3. You get a verdict with reasons — every flag carries a plain-English explanation and a weight, so the score is transparent, not a black box.

    The engine is deterministic: the same input always gives the same score. It is a pattern-and-heuristics engine, not a live language model — the README explains how an LLM layer would plug in.

    Red flags to know

    Double-your-money giveaways“Send 0.5 ETH, get 1 ETH back.” No real giveaway asks you to send funds first.
    Seed phrase requestsAnyone asking for your seed phrase or private key is stealing your wallet. Full stop.
    Lookalike domainsbinance-secure-login.com is not binance.com. One letter is all it takes.
    Fake airdropsReal airdrops never ask you to connect to a random site or send funds to “claim”.
    Guaranteed returns“500% APY, risk-free” is a promise no honest project can make.
    Urgency pressure“Act in 1 hour or lose everything” exists to stop you thinking.
